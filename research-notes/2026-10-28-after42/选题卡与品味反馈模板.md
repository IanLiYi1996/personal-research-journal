# 选题卡与研究品味反馈模板

这是借鉴 After42 思路的个人工作模板，不是其原始 prompt 或已经验证的复现实验。

## 1. 方向卡

- 我希望理解的现象／机制：
- 为什么现在值得研究：
- 已有知识与最接近的工作：
- 当前缺少的理解：
- 可以使用的数据、工具与验证方法：
- 明确不做的事情：
- 时间、候选数、轮次、token与费用上限：

## 2. 候选问题卡

- 问题 ID 与版本：
- 一句话主问题：
- 对象、条件、输入／输出、量词或评价指标：
- 自然性：为何选这些对象和条件？
- 最近前人工作及可定位出处：
- 增量：不是简单重述或无意义组合的理由：
- 若成立／有效，会学到什么？
- 若不成立／无效，会学到什么？
- 最小可检查实例：
- 可能反例与失败条件：
- 新颖性状态：已查证／未充分检索／已有相同问题：
- 值得继续投入的具体理由：

## 3. 求解与修订记录

| 项目 | 填写 |
|---|---|
| 原问题 | |
| 实际尝试 | |
| 可复查材料 | |
| 得到的部分结果 | |
| 尚未核验的断言 | |
| 失败原因：反例／方法无效／预算不足／规格错误 | |
| 改写后的问题 | |
| 修改由哪项证据驱动 | |
| 是否保留核心目标 | |
| 投入时间与资源 | |

不要把求解超时当成困难性证明，也不要把写出的论证当成已核验的证明。

## 4. 品味反馈卡

至少保留几个你真正喜欢与不喜欢的例子；数量由试点预算决定。

- 具体问题：
- 我的决定：追求／保留分歧／暂停／放弃：
- 主要理由：
- 我重视的理解是什么：
- 模型认为重要但我不认同的点：
- 模型忽略但我重视的点：
- 什么新证据会改变我的决定：
- 与另一个问题相比，我会先做哪个，为什么：

这些是个人偏好的例子，不是领域普遍价值的证明。

## 5. 交给 AI 的任务约束

> 根据我提供的方向和文献，提出有限数量的候选问题。逐项写明最近前人工作、具体增量、正反答案的意义和可检查的第一步。找不到出处时标记不确定，不补造引用。
>
> 对我选中的问题作有预算上限的求解尝试。区分反例、部分结果、尚未核验的推导和预算不足。仅在可复查的发现促使改变时提出修订，说明新旧问题的差异。
>
> 排序时保留有理由的分歧，不将模型一致同意当作唯一录取标准。最终研究选择由我决定。

## 6. 收尾检查

- 能否定位前人工作及其真实结论？
- 是否混用了价值、难度与新颖性？
- 是否为让任务成功而缩窄了目标？
- 能否独立复查关键证据？
- 模型辅助、公开题目来源与具体贡献是否有记录？
- 是否留下下一步，而不只是一段漂亮的研究介绍？
