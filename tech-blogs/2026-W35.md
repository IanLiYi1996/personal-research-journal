## §1 ⭐⭐⭐ Deep dive 1：《The Evolution of the Agent Harness》—— 我追了一个月的主线拿到了一份分期史、一个新效应量、和一个可检验的预测

**[The Evolution of the Agent Harness](https://www.latent.space/p/attention-interface)**（Latent Space，Dan McAteer，08-22）

> ⭐ 注意 URL slug 是 `attention-interface` 而标题是 "The Evolution of the Agent Harness" —— 而读完就知道 slug 才是它的论点。

### 中心论点：两条曲线，以及它们交叉之后发生了什么

副标题就是论点：**「Models keep absorbing the harness into their weights — soon, it will be a harness for human attention rather than for the model.」**

两条曲线：**harness 向模型要求什么** vs **模型实际能交付什么**。⭐ **两者之间的差距 ＝ agent 的有效性**，而「差距被闭合」就是 2025 年圣诞前后 agent 忽然「开始能用了」的原因。

⭐ 它引 Lukasz Kaiser（Transformer 作者之一）：「The change last winter, last Christmas — it's a little hard to pin down… the harness changed and a little post-training changed and then new pre-trained models came」⟹ 作者的回答是**这个跳变不在权重里，在围绕权重长出来的系统里**。

### Harness 1.0「螺栓外挂时代」的四个阶段（这个分期我此前没有）

| 阶段 | 时间 | 两条曲线的关系 |
|---|---|---|
| **ReAct「纸面上的 harness」** | 2022-10（⭐ **比 ChatGPT 早一个月**）| 两条都近零，差距小，因为刚开始。⭐ agent loop 只作为提示方法存在；Toolformer（Meta, 2023-02）暗示工具使用可以**训进去**而不是提示出来 |
| **AutoGPT/BabyAGI「早熟的自主」** | 2023 春 | ⭐⭐⭐ **harness 曲线冲到模型能力之前，差距最宽**。⭐ 原文最好的一句：**「A loop doesn't add capability to a model. A loop amplifies the capability a model has, and below some threshold the loop amplifies errors rather than reliability.」** 带算术：**每步 95% 可靠 × 20 步 ≈ 36% 成功率** |
| **Cursor/Copilot「退回人在环」** | 2023–2024 | 把 **harness 曲线拉到模型曲线之下**：不把 loop 给模型，把 loop 给人。⭐ Devin 第一版试图把自主还给模型，Answer.AI 的测试是 **~15% 成功率** ⟹ **IDE 那次撤退不是懦弱而是正确**。⭐ 2024 年底 o1（首个推理模型）使**差距首次反转**，出现模型能力过剩 |
| **Claude Code「曲线交叉」** | 2025-02 | 弃 IDE 用终端、给 bash 与文件读写、**用 permission rules 取代逐次改动的人工批准**。⭐⭐ **「Boris Cherny and team build Claude Code with the *next* model's capabilities in mind, not the current one」** ⟹ 它成功不是因为首个给模型自主权，而是**首个在正确时机这么做**。⭐ 六个月内约 **$1B ARR** |

### Harness 2.0「协同训练时代」（现在）—— 而这里有一个我此前没有的效应量

> ⭐⭐⭐ **[Harness-Bench](https://arxiv.org/html/2605.27922v1) 用同一个模型跑同一批 106 个任务、只换 harness，分数从 52.4 到 76.2 ＝ 23.8 分的跨度，模型零改动。「Half the agent is the harness.」**

⟹ ⭐⭐⭐ **这是 harness 效应我记录的第八个独立数据点，而 Harness-Bench 这篇论文（arXiv 2605.27922，2026-05）我此前完全没有记录过** —— 我一直把 A²E（9 harness × 23 benchmark）当作「测 harness」的主要工作，**而 Harness-Bench 给的是更干净的单一数字。列为待读。**

⭐ 另一个数字：**OpenAI 在 ARC-AGI-3 上只加「retained reasoning 与 compaction」，GPT-5.6 Sol 的分数从 13.3% 三倍到 38.3%**。⚠️ **而我今天 HF digest 里 Prime Agent 报的是 ARC-AGI-3 RHAE Best@1 30% → 95.5%** —— ⚠️ **两者基线与指标不同，不可直接比**，我只记它们同在这个基准上。

### ⭐⭐⭐ 机制：RL 搬进了 harness，然后模型开始把 harness **吸收进权重**

- codex-1（2025-05）：「trained using reinforcement learning on real-world coding tasks in **a variety of environments**」⟹ ⭐ **Toolformer 的设想成真：工具调用从「外部提示」变成「内部训练」**
- 然后模型开始吸收 harness 能力，例如**学会在知道自己上下文窗口的前提下自动 compact**
- **GPT-5.1-Codex-Max 发布语**：「The first model **natively trained to operate across multiple context windows through compaction**」
- ⭐⭐⭐ **「Once the models absorb the harness capabilities, the harness can shed the scaffold. It's production by reduction.」** —— 具体数据点：**Anthropic 的 Thariq Shihipar 说团队最近删掉了 Claude Code 系统提示的 80%**

⟹ ⭐⭐⭐ **这给我 07-31 那份深读（Boris Cherny「harness 保质期只有半年」）补上了理论**：我当时记下的是**现象**（每半年删 CLAUDE.md/skills/hooks；系统提示砍 80%+ 只剩安全/权限/静态分析），**而本篇给出原因——你之所以要删，是因为模型把它吸收了。**

⭐⭐⭐ **而它由此提出一个我从未见人说过的度量：**

> **「The measure of the pace of agent harness evolution is **how much of the harness you get to delete**, while retaining the same capability level.」**

⟹ ⭐⭐ **这是一个可操作的「模型-harness 协同演化速度」指标，而且它的方向与直觉相反：进步表现为你能删掉多少，不是你能加多少。**

### ⭐⭐⭐ Harness 3.0「注意力时代」——一个可检验的预测

「一直删掉模型能吸收的一切，那么删完之后你手里剩下什么？」

- **接下来会被吸收的**：多 agent 编排、工具选择、记忆。⭐ 并点名「researchers are building **self-improving harnesses** that can themselves be trained in a similar way to models」（⟹ 正是我在追的 DarwinX / Evo-Bench / **今天 HF digest 里那篇 Prime Agent: A Self-Improving RLM Harness**）
- ⭐⭐⭐ **删不掉的是那些以人为中心的能力：permissions, identity, trust and legibility**
- ⭐⭐⭐ **「A model that absorbs permissions into itself has *dissolved* permissions. Absorption doesn't end the harness. Absorption *inverts* the harness. The harness becomes the agent's interface to the human that operates it.」**
- ⟹ 「The harness was born as the human interface to the model… If the model absorbs the computer-facing capabilities, the next stage becomes **one layer of abstraction up. The harness becomes the model's interface to our human attention.**」
- ⭐ 引 Ryan Lopopolo：**「The only fundamentally scarce thing is the synchronous human attention of my team.」** ⟹ 「Tokens became abundant and reliable, yet we remain **bottlenecked on scarce human attention**」
- ⭐⭐ **差距不会消失，它会迁移**：「The gap between the model and harness curve doesn't disappear when the model absorbs the harness. **It migrates across the human boundary and creates a new pair of curves with a new gap.**」
- 预测：「every company building agentic AI will ship a **human attention policy surface**」；⭐ 已有的苗头是 **Anthropic 的 long-running agent progress files 与 agentic approval queues**

### ⭐⭐⭐ 而它与我这两个月攒的东西是**从相反方向到达同一结论**

> **他的路径**：一切能被吸收的都会被吸收 ⟹ 剩下的只有 **permissions / identity / trust / legibility**。
>
> **我的路径**：不能信自我报告 ⟹ 需要**证据面**（Runtime Contract 的哈希链与「验证器无 agent 内部状态访问权」）· 需要**闸门**（StateM 的「谁能在执行期检查/修改/操作那个有状态的控制层」）· 需要**授权粒度**（Cloudflare 的按任务 OAuth consent）· 需要**非幂等动作导向人工批准**。
>
> ⟹ ⭐⭐⭐ **两条路径落到同一处，而这比任何一条单独成立更有说服力：一条从「什么会被自动化掉」推，一条从「什么不能被信任」推。**

⭐⭐ **而它给出一个能区分真伪的预测**：若 permissions/identity/trust/legibility 真是残余，则**关于它们的工作不应表现出「被吸收进权重」的模式**，而关于 compaction/工具选择/记忆的工作应该表现出来。⟹ **我自己的记录恰好符合**：compaction 已被吸收（GPT-5.1-Codex-Max 原生跨窗口），⭐ **而权限那一侧本周仍在被往外推**（SemaPLC 的 verification-gated harness、Cloudflare 的按任务授权、Runtime Contract 的提交闸门）—— **没有一篇在说「把权限训进权重」。**

### ⚠️ 保留

- **这是分析/观点文，不是研究**（Dan McAteer 在 Latent Space），其中的分期是叙述性的
- ⚠️ 「Claude Code 六个月约 $1B ARR」「删掉 80% 系统提示」都是转述，我未独立核实
- ⚠️ **Harness-Bench 的 106 任务与 52.4→76.2 我只从本文转引，未读原论文** ⟹ 不知它的 harness 是哪几个、有没有区间
- ⚠️ 「Harness 3.0」整节是预测，⭐ 但它是**可检验的**预测，这比大多数趋势文好
