## Top Highlights

- [Amazon CloudWatch announces managed Prometheus collectors](https://aws.amazon.com/about-aws/whats-new/2026/07/cloudwatch-managed-collectors/) — **High**。此前把 Prometheus 指标送进 CloudWatch 必须自己部署/扩容/维护 OpenTelemetry Collector；现在只给一份 scrape 配置 + 资源连接，采集面由 AWS 托管。覆盖 EKS / EC2 / ECS / MSK / OpenSearch，指标以 OTel 格式落地并可用 **PromQL** 与 AWS 原生指标同表查询（统一告警 / 看板 / 跨服务关联）。支持 Kubernetes service discovery（EKS）与 DNS-based discovery。**观测栈"少一个要自己养的组件"** 是这条的真实价值。
- [AWS Lambda now supports Java 8, 11, and 17 on Amazon Linux 2023](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-lambda-java-amazon-linux/) — **High（运维紧迫性）**。托管 runtime + 容器基础镜像双形态。存量 Java 8/11/17 函数跑在 **AL2 上，而 AL2 已于 2026-06-30 EOL**，要保住支持覆盖与 SLA 资格必须迁到 AL2023。AWS 首推路径仍是升到 **Java 21 / 25**；这批新 runtime 是"暫不动 Java 版本也能先迁 OS"的解耦选项 —— 把一次双重升级拆成两步。
