### 1. Agent 平台侧继续「记忆 + 策略 + harness」三件套打包推进

[AgentCore 在 GovCloud (US-West) 同时上线 memory / policy / harness](https://aws.amazon.com/about-aws/whats-new/2026/08/agentcore-memory-policy-harness-govcloud/)。虽然只是区域扩张（故标 Low），但值得记的是**这三个能力被作为一个整体交付**，而不是各自独立发布：

- **memory** — 短期（会话上下文）+ 长期（跨会话抽取持久化洞察与偏好）
- **policy** — 自然语言写策略 → 自动转成 Cedar → 挂在 AgentCore gateway 上，**每次请求在放行前评估**工具访问权限，且**运行在 agent 代码之外**
- **managed harness** — 声明式定义 agent 的模型 / 工具 / 指令

这正是 `weekly/2026-W32b.md` 那条 arc（「agent 从函数变成有状态长期进程」+「写入前设准入闸门」）的产品侧对应：**policy 在 gateway 层前置评估、位于 agent 代码之外**，与 LongHorizon-Harness 里「executor 声明不能直接改状态」是同一种把权限判定移出被判定者的设计。落到 GovCloud＝这套抽象已经被认为足够稳定到进受监管环境。

### 2. AWS 开始把「服务的正确用法」直接封装成 agent skill

[Amazon Cognito 成为 Agent Toolkit for AWS 的核心 skill（`aws-auth`）](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-auth-agent-skill/)。覆盖 user pool / app client 配置、managed login 与 OAuth 2.0 流、token 管理、JWT authorizer、passkey/WebAuthn 注册、威胁防护、Lambda trigger 接线、identity pool。配合 AWS MCP Server 时，agent 执行 CLI 命令走 **IAM guardrail + CloudTrail 审计**。

值得注意的方向：厂商不再只提供 API 文档等 agent 自己摸索，而是**把 best-practice workflow 作为可分发工件（skill）交付**，并在执行侧配一层权限与审计。这跟社区侧「adversarial reviewer 成可传播 skill」是同一形态在官方渠道的出现——skill 正在成为一种一等交付物。（Cognito 恰是认证类服务，配错就是可公开访问的资源，这个封装动机很直接。）

### 3. 安全自动化：把「手工到期续期」这类人肉环节吃掉

[VPC IPAM 支持 BGP route protection 监控 + delegated RPKI](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-vpc-ipam-bgp-rpki-byoip/)：单一 dashboard 看全组织跨账户跨区域 BYOIP 前缀的 RPKI 有效性 / ROA 强度 / 路由重叠（可指示劫持），并区分 strict 与 permissive ROA；delegated RPKI 与 RIR（ARIN/RIPE/APNIC/LACNIC）一次性对接后，**IPAM 自动在 BYOIP 预配时建 ROA、到期前自动续、也管本地前缀的 ROA**。此前全靠人工在 RIR 侧建与续——典型的「靠人记得续期」失效点被消掉。

[IAM Identity Center 的 multi-Region 一键化](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-iam-identity-center-supports-one-click-multi-region-option-new-organization-instances)同属这条线：原先要手建客户托管 KMS key、配 key policy、逐个加区域，现在建新组织实例时三选一（单区 / 多区 / 自定义），多区选项自动创建 multi-Region CMK 并复制实例——目的是**主区域故障时账号访问不中断**。⚠️ 仅对**新建**组织实例有效，已有实例不适用。

### 4. 其余两条

- [Timestream for InfluxDB 支持备份/恢复](https://aws.amazon.com/about-aws/whats-new/2026/07/timestream-influxdb-backup-restore/)：按需 + 定时（时/日/周/月/自定义，每资源最多 4 套配置、各自保留期），首份全量后**增量**；可恢复为新资源或原地替换，InfluxDB 2/3 引擎均支持。补上的是一个托管数据库的基本盘能力。
- [EC2 R8i / R8i-Flex 上线 Europe (Milan)](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ec2-r8i-r8i-flex/)：定制 Intel Xeon 6，官方数字为对上代 Intel 实例性价比 +15%、内存带宽 2.5×，对 R7i 性能 +20%（PostgreSQL 最高 +30%、NGINX +60%、深度学习推荐模型 +40%）。R8i-flex 是首个内存优化型 Flex 实例。

## Open Questions

- AgentCore 的 policy 用自然语言写、自动转 Cedar——**转换本身的正确性谁来验证**？这正是本周 cross-digest 主线「不能信自我报告」的下一个落点：策略是安全边界，若生成环节没有独立校验，就等于让被约束方参与写约束。（Bedrock Automated Reasoning 的策略自动精化是否会接进来值得追。）
- `aws-auth` skill 覆盖了 Cognito 的正确用法，但**是否包含「不要做什么」的反向约束**（例如不要建开放 principal、不要暴露 unauthenticated identity pool 角色）？skill 作为交付物，负面清单比正面 workflow 更难写也更值钱。
- delegated RPKI 把 ROA 生命周期交给 AWS——**若 IPAM 侧误判导致 ROA 错误，路由影响是全互联网可见的**，回滚路径和责任边界文档尚未看到。
