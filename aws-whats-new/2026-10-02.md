### 内容

- ⭐⭐⭐ **AWS Well-Architected Agent（预览）**：一方 AI agent，「the next-gen evolution of AWS Trusted Advisor and the AWS Well-Architected Tool」—— 关联指标与应用拓扑、**分析 Terraform / CDK / CloudFormation 模板，给出「automation-ready fixes」**，按业务目标排序建议。⭐ 这是 AWS 一方 agent 谱系的又一个（DevOps Agent · Security Agent ＝ Continuum · Transform · 今天的 WA Agent），⭐⭐ 而它的姿态是**审计者而非执行者**：读 IaC、产出可自动化的修复，但「apply」留给人 ⟹ 与 Runtime Contract「非幂等动作导向人工批准」同向；⚠️ 未读它能否直接执行修复，这是最该追的一点。
