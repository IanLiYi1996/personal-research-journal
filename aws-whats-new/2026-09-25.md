### 内容

- ⭐⭐ **AWS Network Security Manager GA（N. Virginia）**：组织级网络安全策略的集中部署与强制执行，**首发管 WAF 与 Shield Advanced、Network Firewall「soon to follow」**；always-on 自动把保护应用到面向互联网的 ALB / CloudFront。是「把安全从逐资源配置移到组织级策略」的又一格，与 W38 那条 `Manage end-user OAuth consent for AI agents` 同属「集中授权/策略面」的方向；⚠️ 目前只有一个区域。
- ⭐⭐ **Billing and Cost Management 新 API `ListBillingViewSegments`**：返回账户在计费层级里的**位置随时间的分段**（管理账户 / 成员 / billing group primary、billable vs pro forma），**原文明写「You can call the API directly or through an AI agent」**、且「billing context can change mid-period, the API divides the requested period into time segments」⟹ ⭐ 这恰是我 W37 cross-digest 那条判据（「一个读数是被测对象 × 读取时刻的函数」）在厂商 API 设计里的形态：它不返回一个值，返回带生效区间的分段。成本治理线上第一个**为 agent 消费而设计**的只读上下文接口。
- ⭐ **EventBridge 重发 Custom event bus**：严格顺序、CloudEvents 等开放格式、内建保留、跨账户经 RAM 共享、新的发布 API。⭐ 「strict ordering ＋ retention」是把消息总线往「可重放的持久事件日志」推，落在「让状态持久」线的基础设施侧。
- ⭐ **Lambda durable functions 进 European Sovereign Cloud**：`step` / `wait` 原语、检查点、暂停不计费；同 feed 里还有它与 **Pydantic AI 的集成**（每次模型/工具调用是一个 durable step，中断后不重付 token）⟹ 「让状态持久、让 agent 短命」那条五篇共振现在有一个厂商原语在主权云里也可用。
- ⭐ **RDS for PostgreSQL 支持后量子 TLS 密钥交换**（PG 18+，`ssl_groups` 参数）⟹ 后量子攻防线（W31f）第一次落到托管数据库的传输层。
- **HyperPod Inference Gateway**：Kubernetes 原生、GPU 感知的推理路由，单个 EKS add-on，按实时推理信号而非 round-robin 路由，一个网关多模型；⚠️ 「首 token 延迟最多降 82%、p99 TTFT 降 97–98%」是 **up-to 且限定在 mixed-hardware / burst 场景**，先存档。落在路由主线的**集群内**层（与 09-15 的 prefix-aware routing 同层）。
- 其余：EMR on EKS 的 Spark Connect 交互式会话（持久 Spark context 跨 cell）· PostgreSQL 19 Beta 4 进 RDS Preview Environment · RDS MySQL Extended Support 小版本 · ElastiCache Global Datastore 标签与 tag-based 访问控制 · RDS SQL Server Developer Edition Multi-AZ · GameLift Servers 5 区域 8 Local Zones。
