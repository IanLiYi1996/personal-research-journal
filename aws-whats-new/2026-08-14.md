## 🚨🚨 本份最重要的不是内容，是一次「静默假零」——以及我给脚本加的守卫

**本次第一次运行，脚本报的是 `0 items, 0 prose lines kept`。** 周五凌晨 03:10、过去 24h 零公告 —— **这完全合理，我本来会照惯例写一份「空档」日报。**

⭐ **但我按 CLAUDE.md 的要求手工核了一遍 RSS 的时间边界，结果对不上:我自己数出过去 24h 有 9 条。**

**根因（不是脚本 bug，是我的操作错误）:**

| 事实 | |
|---|---|
| 脚本从**固定路径** `/tmp/aws-rss.xml` 读取 | `scripts/aws_whats_new.py:12` |
| 我这次把 RSS 抓到了 `$CLAUDE_JOB_DIR/tmp/aws-rss2.xml` | 为了顺手做时间边界分析 |
| ⚠️ 于是脚本解析的是一份 **08-13 09:03 的旧文件** | 整整一天前 |
| 重抓到正确路径后 | ⭐ **9 items, 2 highs** |

> 🚨🚨🚨 **这个失效形态危险的地方在于它与真实空档完全同形。** 「0 条」在周末、周一上午、或任何一个安静的凌晨都是合理输出，**产出里没有任何东西能区分「AWS 没发」与「我读了一份旧文件」。**
> ⭐⭐⭐ **而这与 CLAUDE.md 里我记的 cron「静默停跑」是同一类问题**：那条我写的是「**事后很难与「当天真的没内容」区分（08-01/08-02 那次漏跑就是这个形态）**」。**今天这次是同一形态的第二个实例，只不过原因从「任务没跑」变成「任务读了旧输入」。**
> ⭐⭐ **我之所以抓到它，唯一的原因是我独立做了一次 RSS 边界核算** —— 也就是「用第二数据源复核」这条纪律。**如果我省掉那一步，这份日报会带着一个假的零落盘。**

### ⭐ 修法：给脚本加一个新鲜度守卫（已改并自测）

```python
MAX_RSS_AGE_MIN = 60
...
age_min = (dt.datetime.now().timestamp() - RSS.stat().st_mtime) / 60
if age_min > MAX_RSS_AGE_MIN:
    print(f"RSS at {RSS} is {age_min:.0f} min old (limit {MAX_RSS_AGE_MIN}). "
          f"Re-fetch it before running: curl -s ... -o {RSS}", file=sys.stderr)
    return 2
```

**自测（把 mtime 改成 3 小时前）:**
```
RSS at /tmp/aws-rss.xml is 180 min old (limit 60). Re-fetch it before running:
  curl -s "https://aws.amazon.com/about-aws/whats-new/recent/feed/" -o /tmp/aws-rss.xml
退出码: 2
```

> ⭐⭐ **我认为这个改动的性质与我平常拒绝改的那类不同，所以值得说清界线:**
> - **我 08-11 拒绝改的**是「把 `ec2` 加进 `HIGH_HARD`」——那是**调启发式**，会引入「顺带提及即升级」的系统性假阳性（实测 5 处翻转只有 1 处是想要的）
> - ⭐ **今天这个是正确性守卫**：它不改变任何判断，只在输入明显不可用时**拒绝产出**。⭐ **判据是「失败会不会静默」——会静默的失败必须变成硬失败。**

### ⭐⭐⭐ 最该记的方法学教训：双源一致**不能**防回填

08-13 那份我特意写了一句自我加强的话：**「这是我做双源复核以来第一次两源在一个反常值上完全对齐，反而增强了这个反常值的可信度。」**

> ⭐⭐⭐ **这句话是错的，而且错法有名字。** 两个源同时说 6，**不是因为它们独立确认了 6，而是因为它们读的是同一个上游、在同一时刻都还没拿到那三条。** ⟹ **双源一致只排除「我这边的抓取管道坏了」，完全不排除「上游此刻尚不完整」。**
> ⭐⭐ **这与 CLAUDE.md 里那条 Varnish 缓存教训是同一个形状**（「已成功取过的 id 全返 200」看着像恢复了，其实是缓存命中、源站仍在限流）——**两处都是「两次探测看似互相印证，实则共享同一个会骗人的中间层」。**
> ⭐ **可推广的判据：多源核验只能证伪「我的读取有问题」，要证伪「上游不完整」必须在不同时刻重读同一个日期。** ⟹ **凡是「某天只有 N 条」「某天首条特别晚」这类关于某一天完整性的断言，都必须隔天复核后才能下。**
