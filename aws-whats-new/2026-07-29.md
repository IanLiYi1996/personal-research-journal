## Top Highlights

- [Amazon S3 Tables now support the Variant data type for Apache Iceberg V3](https://aws.amazon.com/about-aws/whats-new/2026/07/amazon-s3-tables-variant-iceberg-v3/) — S3 Tables 跟进 Iceberg V3 规范的 Variant 类型：JSON 等半结构化数据可**免预定义 schema 直接写入**，引擎在写入时把它 shred 进隐藏列并生成 Parquet 列统计，从而仍能享受 file pruning；S3 Tables 的自动 compaction 也覆盖 Variant 列。这是「湖仓吞掉半结构化数据」路线上的实质一步——过去要么先定 schema，要么放弃谓词下推。
- [Amazon EKS Provisioned Control Plane now delivers faster pod autoscaling](https://aws.amazon.com/about-aws/whats-new/2026/07/amazon-eks-provisioned-control/) — HPA sync 并发度提到 Kubernetes 默认值的**最多 40 倍**，对跑成百上千个 HPA 对象的集群是真实的扩容延迟改善；也是「托管控制面替你调参」这一 EKS 差异化叙事的又一笔。

## 观察

- **DataSync Enhanced mode 一天两发，补齐 source/destination 矩阵**：EFS + FSx for Lustre（无需 agent），以及 HDFS + Azure Blob + 自管对象存储（agent-based，agent 现可部署在 Microsoft Hyper-V 上）。官方文案明确把 **agentic AI 与 ML 训练**列为大规模迁移的头号场景，与 HPC / 基因组 / 媒体渲染并列——「数据搬运服务把 AI 训练当主要卖点」这条线在 AWS 侧继续显影。HDFS 侧支持多 NameNode HA + Kerberos 下的 TDE，指向受监管行业 PB 级加密 Hadoop 集群的搬迁。
- **两条 Storage 主线同日出现**：一边是把外部数据搬进来（DataSync），一边是让搬进来的半结构化数据免 schema 可查（S3 Tables Variant）。
- **主权云 / 区域扩张各一条**：Outposts 第二代进孟买（数据驻留 + 低延迟本地负载，覆盖印度境内外客户），European Sovereign Cloud (Germany) 补上 Console Home 的 Cost and Usage widget——主权云仍处在逐个补齐常规控制台能力的阶段。
