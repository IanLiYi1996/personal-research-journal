## Top Highlights

- [AWS Managed Microsoft AD now supports Standard to Enterprise Edition upgrade](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-microsoft-ad-edition-upgrade/) — **High**。此前撞到 Standard Edition 的 **5,000 用户/对象**上限，唯一出路是新建 Enterprise 目录 + 重新 join 所有工作负载 + 重建信任关系，是典型的高风险停机迁移。现在可从控制台/CLI/API **原地升级到 Enterprise（上限 500,000 对象）**，且明确保留既有 trust relationships、应用集成、group policies，不需改 DNS 配置或改动已连接的 AWS 工作负载。全区域可用。对增长中的 AD 依赖型企业，这是把一次"项目级迁移"降级为一次"运维操作"。
- [AWS IAM Identity Center extends multi-Region support to Identity Center directory](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-iam-identity-center-extends-multi-region-support-to-identity-center-directory) — **High**。多区域复制此前只对**接外部 IdP** 的 organization instance 开放；现在用 **Identity Center 内建目录**作身份源的实例也能从主区域复制到任选附加区域。AWS 会自动复制身份、授权（entitlements）等信息，主区域中断时用户仍可凭已下发的 entitlement 访问账号 —— 即 **SSO 不再是主区域的单点**。同时解锁数据驻留 / 就近部署两类合规诉求：应用管理员按标准流程在附加区域部署应用，Identity Center 仍在主区域统一管理。
- [Amazon OpenSearch Service now supports OpenSearch version 3.7](https://aws.amazon.com/about-aws/whats-new/2026/07/amazon-opensearch-service/) — **High**。三块改进：① **向量成本** —— Faiss 与 Lucene 引擎支持 **1-bit 标量量化**，压缩向量以降存储/内存，官方口径保持检索精度；且改用 **doc values 而非 document source** 取向量，更快且**无需 reindex**（对已上量的向量库是零迁移成本的加速）。② **相关性评测** —— Search Relevance Workbench 加新评测指标、CSV judgment 上传、扩展 hybrid search 调优。③ **Query Insights** —— 自动查询建议、finished-queries cache、top query 数据导出到 S3，用于定位贵查询与看趋势。全区域可用。

- **向量检索的成本线继续往下压**：1-bit 标量量化落到 Faiss / Lucene 两个引擎，是本次最实在的一项 —— RAG 类负载的瓶颈通常是向量的内存驻留量，不是 QPS。
