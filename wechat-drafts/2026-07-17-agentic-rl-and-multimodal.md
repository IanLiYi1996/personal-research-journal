# 训练 GLM-5.2 的 RL 算法论文出来了：我扒出了 2026 年 AI 的两条隐藏主线

> 上一篇我写三家开源巨兽（Inkling / GLM-5.2 / Kimi K3）的时候，留了个坑：
> GLM-5.2 官方说自己用了"异步 Agent RL"，但**具体怎么做的，语焉不详**。
> 这几天扒最新论文，那篇算法论文**真的出来了**——而且它只是一条更大主线的冰山一角。

---

## 起因：两个检索工具，一条意外的线索

我用 HuggingFace 和 alphaXiv 交叉检索 2026 年的新论文（重点盯 LLM / Agent / 多模态）。结果 alphaXiv 一口气返回的十几篇里，**至少 10 篇在攻同一个问题**。

这种"扎堆"通常意味着一件事：**某个技术瓶颈到了集中爆破的时刻。**

于是我挑了 5 篇标杆，全文读完。它们分成两条主线，下面一条条讲。

---

## 主线一：Agentic RL 的「信用分配」爆发

先说人话版的问题。

RL 训练数学、代码这种**单轮**任务很好办：答案对不对，一个检查器判了给分。但训练 **Agent** 就麻烦了——一个 agent 完成任务可能要搜几十次、点几十下、改几十个文件。最后只有一个"成功/失败"的信号，**它没告诉你：哪一步搜到了关键证据、哪一步在瞎逛、哪一步把事情搞砸了。**

一次失败的尝试里，可能前面很多步其实是对的。但"只看结果"的训练，会把这些好动作和最后那个错误**一起打上负分**。这就是"信用分配（credit assignment）"问题。三篇标杆给了三种解法：

### ① TRACE：不训评论家，用"冻结的自己"当尺子

（UW-Madison + Microsoft，7 月 15 日）

它的巧思是：拿一个**冻结的参考模型**（就是训练开始时策略的副本），去衡量**每一步操作有没有让"正确答案"变得更容易预测**。

变容易了 → 这步加分；没用 → 约等于 0 分；变难了 → 扣分。而且这个设计有个漂亮性质：**中间瞎凑步数没法刷分**（数学上首尾相消）。

效果很硬：Qwen3-4B 在深度检索基准 BrowseComp-Plus 上，从 **7.2 分直接干到 35.6 分**，且不需要任何 SFT 冷启动。

> 关键是：**它不需要额外训练一个评论家模型，也不要人工标注每一步。**

### ② SAO：训练 GLM-5.2 的那套算法，终于有论文了

（清华 + Z.AI，7 月 8 日）

这就是开头说的那篇。论文明确写了：**"成功部署在训练开源 GLM-5.2 模型（750B-A40B）的 agentic RL 流程中。"**

它解决的是"异步 RL"的稳定性。传统 RL 是同步的——生成一整批再统一训练，但 agent 任务有的快有的慢，快的干等着慢的，GPU 大量空转。异步能提速，但会不稳定，而且主流的 GRPO 算法**天生和异步不搭**（它的分组采样必须等最慢的那条）。

SAO 的解法是：**每个任务只采一条轨迹**、生成完立刻进训练，配一个更强的价值模型来压方差。还有个细节很妙——agent 轨迹里"环境返回的内容"不是模型自己生成的，算梯度时会引噪声，SAO 直接**跳过环境反馈**、把相邻的模型动作连起来算。

结果：普通 GRPO 训到约 160 步就崩了，**SAO 能稳训 1000 步**；AIME2025 从 84 分拉到 **97.3**。

### ③ TRIAGE：给每个动作贴"角色标签"

（LinkedIn + Harvard + JHU + GaTech，6 月 30 日）

思路更直觉：让一个裁判把每个动作分成四类——**决定性进展 / 有用探索 / 无进展 / 倒退**，再按角色给分。

消融实验发现最有价值的是**识别"倒退"**（成功轨迹里那些其实帮倒忙的动作）。附带好处：agent 学会少做冗余操作，交互轮数直接降了 10–15%。

**三篇的共同点很有意思：它们都保留了"最终结果对不对"这个锚，只是在它之上加密集信号。没人敢把可验证的结果奖励整个丢掉。**

## 主线二：统一多模态，正在拆两个"预训练包袱"

第二条线关于"既能看图又能画图"的统一多模态模型。主流做法有两个包袱：骨干多用**自回归（AR）**，视觉靠**预训练编码器**。两篇标杆分别拆其中一个。

### ④ LLaDA2.0-Uni：不用 AR，改用"扩散大模型"

（蚂蚁 Inclusion AI，HuggingFace 上 245 个赞）

它把骨干换成**离散扩散大模型**，理解和生成共用同一个训练目标。图像先用一个"语义 tokenizer"转成离散 token，生成时再用扩散解码器还原成高清图（蒸馏到 8 步，比 50 步快 11 倍）。

结果：理解上**追平专用 VLM**（MMStar 64.1 对 Qwen2.5-VL 的 63.9），生成上多个基准拿下统一模型 SOTA，还原生支持"边想边画"的交错推理（分步解物理题、下棋）。

### ⑤ Tuna-2：像素直接喂，干掉视觉编码器

（Meta AI + HKU + Waterloo）

主张更激进：**预训练视觉编码器根本不是必需的**。直接把原始像素切块喂进去，VAE 和编码器全删掉，理解和生成都在像素空间端到端做。

最有价值的发现来自控制实验：带编码器的版本**早期收敛快**（有语义先验），但**大规模训练后，没编码器的 Tuna-2 反超了**——尤其在需要细看图的细粒度任务上。

> 一句话洞见：去掉编码器自带的"归纳偏置"（固定分辨率、丢失低层细节），反而更利于大规模学到强表示。

## 两条线，一个共同的信号

把 5 篇串起来看，我发现一个反复出现的规律：

**大规模训练之后，简化的架构反而会超过带着复杂先验的架构。**

- Tuna-2（无编码器）> Tuna-R（有编码器）
- 扩散 LLM 追平精心设计的 AR VLM
- 信用分配上，连"不训评论家"的 TRACE 都能打

还有一个意外的交汇：**去编码器化**。上一篇的 Inkling（音视频无编码器）、这篇的 Tuna-2（视觉无编码器）、LLaDA2.0-Uni（语义离散 token 统一），都在弱化或取消模态专用编码器，让统一骨干直接吞原始信号。

## 我读完想到的几件事

1. **信用分配是 2026 Agentic RL 的头号战场。** 结果奖励太粗，怎么给轨迹内部的每一步分账，成了兵家必争之地。

2. **后训练的"工程基础设施"已经是核心竞争力。** SAO 证明异步 RL 不只是提速，算法本身得为异步重新设计。这和 GLM 的 slime 是一条线。

3. **别小看"简化"。** 删掉编码器、换掉自回归、砍掉评论家——2026 的多个突破都来自"做减法"而非"堆复杂度"。

4. **两条线可能要交汇了。** 统一多模态模型的 agentic RL 后训练该怎么做信用分配？已经有人（Relax）在试 omni-modal 异步 RL 了。
