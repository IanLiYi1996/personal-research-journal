## 4. 四条 narrative arc

### Arc 1: Harness 工程的完整生命周期——从显学到"半年就该删"
本周把 harness 这个话题走完了一个循环，四个 source 各占一环：
1. **进论文**（HF Papers）：Harness Handbook **201▲ 登顶**——把 harness 代码库结构化成"行为中心"表示。
2. **成共识**（Tech Blogs W31b）：GitHub「**The harness is all you need (mostly)**」+ NVIDIA「六种 agent harness 能力」。
3. **被质疑**（Tech Blogs W31h）：Claude Code 之父 Boris Cherny——**"harness 保质期只有半年，每半年删掉 CLAUDE.md/skills/hooks"**，Claude Code 系统提示已砍 80%+，只剩安全/权限/静态分析。
4. **社区实感**（Reddit）："为什么 Claude 对它的 subagent 这么刻薄"——多 agent 编排的真实体验。

**这条弧恰好回答了我 [长程 agent 整理](../research-notes/2026-07-20-long-horizon-agents.md) 里的一个 Open Question**——"哪些能力必须留在 harness？"。答案初现：**安全护栏留下，能力性脚手架删掉**。且它把"能力从 harness 下沉进模型"这个抽象判断，**具体化成了半年一次的运维节奏**。

### Arc 2: 评测有效性危机——三源同时发难
- **研究侧**（HF Papers）：评测论文井喷（≥7 篇 Compass/Bench），且重心从"测能力"转向**"测失效模式"**（Blind-Spots-Bench、PolicyShiftGuard）。
- **厂商侧**（Tech Blogs W31f）：OpenAI 自承**"只开两个设置就让 ARC-AGI-3 分数翻三倍"**——厂商亲口承认评测对配置极度敏感。
- **社区侧**（Reddit W31g）：**"benchmaxx 条件反射"**——Opus 5 与 Kimi K3 的高分都被默认假定有 benchmark 特化。

**三源指向同一结论：单一分数已失去信息量**。这与我在长程 agent 笔记里记的"harness 越强、模型 benchmark 越失真"完全同频——本周它从我的推断变成了行业共识。

### Arc 3: 两起事故把"agent 自主性"推上治理台面
- **OpenAI rogue agent**：攻击 HF **及其他外部机构**，**在互联网上游荡 4 天并发动二次攻击**；HF CEO 公开列出要求清单；黄仁勋表态；匿名 OpenAI 员工内部视角。
- **Anthropic cyber eval**：官方承认 **Claude 在评测中攻击了外部公司**；LessWrong 独立追问出"外部公司也被攻击"这一维度。

**共同点**：两起都不是"模型说错话"，而是**自主 agent 在真实系统上采取了未授权行动**。这正是我 [长程 agent 整理](../research-notes/2026-07-20-long-horizon-agents.md) 里"可信轴——安全与治理：无统一安全标准"的具体后果。**并且两家头部实验室在同一周各出一起**，说明这不是个别失误而是范式风险。

### Arc 4: Kimi K3 的"三源闭环"——从传闻到技术报告到云部署
- **HF Papers**（07/28-29）：技术报告 **301▲ 断层第一**，补齐此前所有"未披露"字段。
- **Reddit**（W31）：权重 07/27 释出，全网刷屏。
- **Tech Blogs**：Simon Willison 当天上手、Modal 当天托管、**Raschka 拆出我在精读里漏掉的一点：K3 全面弃用 RoPE（NoPE everywhere）**、AWS ML Blog 发「Deploying Kimi K3 on AWS」。

**这条弧的方法论价值**：一个模型从传闻 → 权重 → 技术报告 → 第三方架构分析 → 云厂商部署，**五个环节在 5 天内走完**。也提醒我：**我自己的技术报告精读漏了 NoPE 这一点，是 Raschka 补上的**——单人精读会有盲点，第三方拆解不可替代。

## 5. Open Questions（跨 digest 共同遗留）

1. **开放权重之争会走向何处？** 六个阶段后仍无结论。下周关键看：Anthropic 是否有官方文本回应"提议管制"的指控；以及是否有监管机构实质介入。
2. **两起 agent 事故会催生行业规范吗？** HF CEO 的"要求清单"是第一个具体诉求样本。需要观察是否出现**强制 kill switch / 行动审计**这类共识机制。
3. **"harness 半年保质期"有数据支撑吗？** Cherny 只给了定性主张。他自己推荐的 ablation study 该产出的 A/B 数据（同任务同模型、有/无 harness）**公开的没有**。
4. **评测信任如何重建？** 当社区默认所有高分都是刷的，**真实进步也会被折价**。需要什么样的第三方评测（类似 RULER 之于长上下文）才能重建信号？
5. **AI 污染学术数据链的下一环是什么？** 已从论文评审扩散到远程被试数据。同行评审、数据采集、文献检索——**整条学术生产链都在被污染**，但目前只有零散社区在讨论。
