## 0. 一句话

**106 篇笔记、220 条关联、17 个社区**。图谱证实了一件我原本只是感觉的事：这个 journal 的重心已经从"每周抓取"沉淀成**几个有内聚力的知识块**（Agent 长程体系 / LLM 效率与长上下文 / 量子计算 / LLM 入门系列）。

> **本文数据已随两轮修正更新（2026-07-30）**：
> 1. **脚本修了一个漏检**：早期版本只识别 `](/dir/x.md)` 绝对路径与 `[[wikilink]]`，**漏掉了同目录相对链接**（如 LLM 入门系列内部用的 `](2026-02-09-llm-intro-architecture.md)）。修复后边数 160→205、孤立 43→29——说明**当初那个 41% 的孤立率有相当一部分是工具误判，不是真缺口**。这是个教训：图谱结论要先怀疑工具。
> 2. **补了两处真实缺口**（见 §4）：LLM 入门 8 篇加系列导航互链、4 篇单点技术笔记与效率块双向补链。边 205→220、社区 21→17、孤立 29→21。

**事后看很合理**：[长程 agent 整理](/research-notes/2026-07-20-long-horizon-agents.md) 连接 4 个社区，因为它的"两支柱框架"天然要引用架构（长上下文）、训练（RL）、harness、评测四类知识——写的时候我刻意把五篇点状笔记连成网，图谱把这个意图**客观量化**了。

**运维含义**：桥节点是**单点故障**。这 6 篇（尤其前两篇）一旦过时或写错，会同时污染多个知识块，值得优先复审。

## 3. 意外连接：图谱发现的、我没意识到的关系

这是 llm_wiki 方法里最有价值的一环——**自动找出跨社区/跨类型却强关联的笔记对**：

| 分数 | 连接 | 为什么意外 |
|---|---|---|
| **4.90** | 长上下文综述 ↔ topics 的长上下文训练页 | **共享 6 篇文献**却分属不同社区——同一主题被我在 topics 和 research-notes 各写了一遍，**存在内容重叠风险，值得合并或明确分工** |
| **4.80** | W30 技术博客周报 ↔ W30 Reddit 周报 | 同一周的两份 digest，共享文献为 0 但被 cross-digest 串起来——**跨源共振被图谱识别出来了** |
| **3.46** | 长程 agent 整理 ↔ Agentic RL Survey | 综述与论文笔记跨类型强关联（共享 2 篇文献） |
| **3.42** | two-harness 对比 ↔ agent-evolution / ai-frontier（两条） | 一篇 research-note 同时锚定多篇 topics 页——它是**跨块的翻译层** |

**最值得动手的一条**：第 1 名暴露了一个**真实问题**——长上下文这个主题在 `topics/` 和 `research-notes/` 各有一篇、共享 6 篇文献。这不是"意外连接"而是**潜在重复**，下次该明确二者分工（topics 做长青索引、research-notes 做时点深读）。

## 4. 知识缺口：补链前后

补链前 43/104（41%）孤立 → **脚本修漏检后 29** → **补链后 21/106（20%）**。

| 类别 | 处理 |
|---|---|
| **历史 HF digest / Reddit 周报** | ❌ **不补**。它们是**素材层**，使命是被综述消费掉，孤立是正常的 |
| **LLM 入门系列 8 篇** | ✅ **已补**：每篇加"系列导航"（返回总索引 + 2–3 篇按主题相关的兄弟篇 + 一句关联理由）。degree 从全 1 变成 2–7 |
| **4 篇单点技术笔记** | ✅ **已补双向链**：continuous-batching / GPU-infra → FlashAttention 篇；DeepSeek-V4 → 长上下文篇；GPT-5.6 → 推理努力度篇；三篇综述也加了回链 |
| **仍孤立的 21 篇** | 绝大多数是历史 digest（设计使然）+ 刚写完还没被引用的新笔记 |

## 5. 这套方法给我的四条实操结论

1. **先怀疑工具，再怀疑知识**。第一版 41% 孤立率里，很大一部分是脚本漏检同目录相对链接造成的**假缺口**。图谱结论必须先验证链接解析是否完备。
2. **"写的时候就串联" 有效且被量化验证**。社区 #6 和多条高分意外连接都是手写交叉引用的产物。→ 继续保持。
3. **素材层与综述层要分开看**。用 degree 一把尺衡量所有笔记不公平——digest 的价值在于被消费。
4. **图谱能发现重复,不只是缺口**。§3 第 1 名（长上下文双写）就是个例子——这是我自己翻笔记不容易发现的。

## 复现

```bash
# 生成洞察报告 + 交互图数据（会写 weekly/knowledge-graph.md 与 assets/knowledge-graph.json）
uv run --with networkx python3 scripts/wiki_graph.py
bash journal.sh index
```

图谱是**快照**：新增笔记后重跑即可刷新。本文解读基于 2026-07-30 补链后的 **106 节点 / 220 边 / 17 社区** 快照。
