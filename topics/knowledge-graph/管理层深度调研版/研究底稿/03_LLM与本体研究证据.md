# LLM 与本体：方法、实验及证据边界

## 范围与判断

仅考察 2023—2026-10-23 公开的学术记录，不包含数据库产品、企业案例及早期传统方法。通过 arXiv 官方 API，以本体学习／对齐、知识抽取／OWL、生成／GraphRAG 三组互补关键词检索，再按 DOI、arXiv ID 去重；保留 27 条相关记录，按任务覆盖及全文可核性选中六篇。两篇 2026 年研究初始仅核元数据；随后仅补核 OntologyAligner 全文，作为末尾近期补充，不扩展六篇核心。这是轻量背景扫描，不是系统综述。Crossref 补核两篇出版信息后，另两次查询返回 429，未重试；合法 arXiv 全文已足以核实核心方法。引用数未取得，统一为 null。

以下证据必须分层：schema 生成提出类、属性及层级；实例抽取填入事实；OWL 公理构建涉及形式约束；对齐预测已有本体间的对应关系；GraphRAG 则组织检索与摘要。产生三元组或输出 OWL 文件，本身均不证明形式推理正确。

## 六篇核心证据

1. **LLMs4OL（2023，ISWC）——本体学习子任务。** 用零样本提示及 Flan-T5 指令微调，测试术语类型、上下位关系与非分类关系；来源包括 WordNet、GeoNames、UMLS、schema.org，各来源并非覆盖全部任务。类型用 MAP@1，关系用精确率／召回率／F1。结果支持任务专门适配的价值，也显示领域差异；不等于从复杂文档自动生成完整、逻辑一致的本体，亦未验证生产维护成本。[论文，§3—4、表3](https://arxiv.org/pdf/2307.16648v2)；[正式出版 DOI](https://doi.org/10.1007/978-3-031-47240-4_22)。

2. **Ontology engineering with Large Language Models（2023，本次按预印本核实）——OWL 公理翻译。** 微调 GPT-3 davinci，将自然语言转为 OWL Functional Syntax，覆盖实例、子类、不相交及基数限制，以 OWLAPI 接入 Protégé。训练／验证分别为150／50组句子—公理对，演示家庭本体；用验证集 token accuracy 选择配置，却未报告独立语义准确率或工时对照。作者明确将定量评价留作后续，因此只能支持受监督原型可行性。[论文，§II—III、结论](https://arxiv.org/pdf/2307.16699v1)。

3. **Ontology Generation using Large Language Models（2025，本次按预印本核实）——需求到 OWL 草稿。** Memoryless CQbyCQ 拆解能力问题，Ontogenia结合设计模式、元认知提示及迭代检查。总数据为10个本体、100个能力问题、29个用户故事；但三模型比较及深入评价只覆盖三个课程故事、45个问题，不能把总规模套到全部实验。评价包含人工交叉检查的 CQ 覆盖、OOPS!严重问题、冗余元素及专家质量判断。“覆盖”指具有编写验证查询所需元素，不保证建模优良或逻辑一致；仍见错误约束、冗余、复杂问题失效与潜在训练泄漏。[论文，§4—6、§9.3](https://arxiv.org/html/2503.05388v1)。

4. **OLaLa（2023，K-CAP）——本体对齐。** SBERT召回候选，开放 LLM 少样本判断等价，再用高精度匹配、一对一及置信度过滤。OAEI实验覆盖解剖、生物多样性、Common KG及仅类匹配的KG任务，报告P／R／F1和时间。默认配置在鼠—人解剖上F1为0.902，但ENVO—SWEET仅0.510，低于表中最佳系统0.713。结果依赖候选召回、提示及后处理，运行常更慢；不能推成普遍优胜，更不代表映射后的联合本体已通过一致性验证。[论文，§3—5、表1](https://arxiv.org/pdf/2311.03837v1)。

5. **Text2KGBench（2023，ISWC）——给定 schema 下实例抽取。** Wikidata-TekGen含10个本体、13,474句，DBpedia-WebNLG含19个本体、4,860句；用Vicuna／Alpaca-LoRA测试文本到事实。七项指标包括P／R／F1、关系名符合度及主语／关系／宾语幻觉。Vicuna在TekGen全部测试的F1为0.35、符合度0.83，说明“用了允许的关系”仍可能抽错事实。此版符合度仅查关系名列表，明确不评价RDF／OWL生成能力，不能当作域／值域或逻辑约束验证。[论文，§1、§4—5、表2](https://arxiv.org/pdf/2308.02357v1)；[正式出版 DOI](https://doi.org/10.1007/978-3-031-47243-5_14)。

6. **From Local to Global（GraphRAG，2024首发，读2025修订版）——检索与全局摘要。** 抽取实体关系、生成社区摘要，再合并回答；在公开播客及新闻语料上，每组125个生成问题，对比向量检索和无图全文摘要。评价为LLM裁判的全面性、多样性、辅助判断与直接性，另以自动抽取声明及聚类计数交叉检查；支持特定全局问题上的相对摘要优势，但不是人工事实准确率、OWL蕴涵或一致性测试，跨领域及幻觉率仍需验证。[论文，§3—6](https://arxiv.org/html/2404.16130v2)。

## 为什么不能换算业务 ROI

综合上述实验，合理定位是“候选草稿或事实的生成助手”，而非无人审核的语义权威。论文中的金标准分数、课程问题覆盖及摘要偏好，均未直接测量企业任务完成、错误损失、审核返工、数据接入、长期维护及模型调用的全成本。抽取正确不代表业务规则完整；检索回答丰富不代表决策正确；文件可解析不代表公理符合领域真实语义。预印本身份和LLM裁判更不能补足这一因果链。若要验证业务价值，应另做同任务的人工作业对照，把来源追溯、约束检查、专家审核及返工成本共同纳入；本扫描不提供企业ROI或替代专家的证据。

## 2026 近期补核：OntologyAligner

arXiv:2609.10055 的首发及更新时间均为2026-09-09，当前提交历史仅有v1，早于本报告截止日。本次实际读取合法PDF全文的结果、方法、局限及补充材料，`full_text_read=true`；按预印本记录，正式出版状态未核实，引用数仍为null。[版本与日期](https://arxiv.org/abs/2609.10055)。

方法分三阶段：以本体标签及同义词训练专属对比学习投影，检索候选概念；LLM结合候选标签、同义词、定义重排；仅当检索与重排首选不同且存在局部父子／兄弟关系时，引入层级证据精修。输入是已抽取的孤立短语，输出已有概念标识，不是新schema生成、两个本体间的公理对齐或OWL蕴涵证明。

主实验在七个HPO数据集汇成的PhenoNormBench上做短语归一化；指标为首位准确率，宏平均等权汇总数据集，微平均汇总所有样本，并报告置信区间、配对检验、消融及难度分层。敏感性实验只用均衡子集，不能等同完整基准验证。MONDO、MEDIC及NCBITaxon扩展实验各自重新训练投影和建索引，部分对照成绩引用已有论文，不是统一重跑或零样本迁移。

局限明确：复杂短语、词面差异仍困难；主要测英语，层级精修只利用局部父子与兄弟结构。论文排除上游实体抽取，完整临床文本处理需后续端到端验证。因此这里只能作为术语归一化的方法证据，不推断诊断效果、真实部署、临床安全性或业务ROI。[全文，第4—17页及补充材料](https://arxiv.org/pdf/2609.10055v1)。
