# 数据库／存储路线产品能力核实

截止：2026-10-23。仅本轮 web.run 读取的维护方正文；未委派、未引用旧笔记、未做性能实测或资源部署。下标链接直达官方页面，完整页名见来源索引。应用补做与算存、备份、运维成本为工程判断，不是厂商功能承诺；不报价。

## 能力矩阵

| 路线／限定文档 | 数据模型与查询 | 原生 schema／关系数量 | 推理、更新删除与应用补做 | 部署及成本组成 |

| Neo4j；Graph types 2026.06 GA、Enterprise、Cypher 25 | 标签属性图；Cypher。[N0] [N1] | 开放 schema：属性类型／存在／唯一／键、隐含标签、边两端标签；未声明的元素仍可存在。所核约束清单未列通用关系度数限制。[N1] | Graph types 不是 OWL 推理承诺；插件兼容性未核实。应用迁移冲突数据、管理 schema 变更与实例清理。[N1] [N3] [N4] | 自管／Aura；自管许可、Aura 内存规格时长，另核算存、备份／运维；不外推各 Aura 档位支持 Graph types。[N5] |
| Neptune Database；在线用户指南 | LPG：Gremlin／openCypher；RDF：SPARQL，两种装载路线不可混称。[P0] | 无显式业务 schema；LPG 约束集中于点 ID 各自唯一、边 ID 各自唯一，点边可同 ID。属性 single／set 不是关系度数契约。[P1] [P2] | OWL 可作为 RDF 存放；官方示范由 Python 补做模型解读和校验，不证明原生任意 OWL 推理。应用补校验、推理、版本迁移及清理范围。[P4] | AWS 托管；实例／Serverless NCU、存储、Standard I/O、备份、传输；I/O-Optimized 不另计读写 I/O。[P5] |
| Neptune Analytics；在线用户指南 | LPG／openCypher；N-Triples 导入映射为点标签、属性、边，不是原生 SPARQL 存储。[A0] [A1] | 导入列类型／属性 cardinality 不等于业务 schema 或边数量约束；后两者未核实。[A2] | 空白节点转成按文件／装载作用域区分的 IRI；应用管映射版本、身份合并、源库同步及删除传播；未核实 OWL 引擎。[A0] | AWS 托管分析库；内存与相应计算／网络容量时长、备份及关联 S3 成本，不按 Database 实例口径套算。[P5] |
| NebulaGraph；公开 3.8.0，非“最新版” | 有向属性图；nGQL，部分兼容 openCypher，不能直接当 Cypher。点可无 Tag 或多 Tag；边只有一个 Edge type。[B0] [B1] | Tag／Edge 定义属性；VID 在 space 内唯一，类型为 int64／fixed_string；边由源 VID、类型、rank、目标 VID 唯一定位，无 EID。rank 不可变，默认 0；这不是度数约束。[B1] | 原生 OWL／规则引擎未核实。允许悬空边；默认删点不删边，WITH EDGE 亦非整体原子操作，应用须维护端点存在、失败重试及迁移。[B1] [B2] | 社区自管 Meta／Graph／Storage 三服务；算存、副本、备份、运维；企业许可另核。[B0] [B3] |
| JanusGraph；官方在线 schema 文档 | 属性图；Gremlin；可嵌入 JVM 或 Gremlin Server。[J0] [J1] | 属性类型及 SINGLE／LIST／SET；边 multiplicity 原生支持 SIMPLE、MANY2ONE、ONE2MANY、ONE2ONE；连接端点标签也可约束。[J0] | OWL／规则引擎未核实。已提交类型定义不能原位改变；重命名后新建类型不迁移旧实例，应用批量转换、重建索引及处理一致性清理。[J0] [J2] | 自管；存储后端与可选搜索索引分别运维，另计副本、备份、算存。[J1] [J2] |
| ArangoDB；3.12 文档 | JSON 文档／键值／属性图；AQL；边文档含 _from、_to。[R0] | 集合 JSON Schema draft-4 忽略系统字段，包括 _from／_to；命名图接口校验端点。唯一索引可限制重复端点对；跨分片范围另核，通用度数未核实。[R0] [R1] [R2] | OWL／规则引擎未核实。schema 可改／移除，但不自动清洗旧数据；命名图删点会清边，原始文档接口可绕过；应用统一写入口、迁移和清理。[R0] [R1] | 自管单机／集群或托管；许可／服务费、算存、备份运维。3.12 已更换源码及社区二进制许可，不能沿用 Apache 2.0 假设。[R3] |
| GraphDB；11.1 文档 | RDF；SPARQL 1.1。[G2] | SHACL minCount／maxCount 等；事务提交校验须建库时启用，不能直接给已有库补开；外部批量校验是另一机制。[G1] | 前向物化；RDFS、Horst、OWL 2 RL／QL、自定义 .pie；QL 有明确不符合项，不是任意 OWL DL。撤回事实会撤回失去依据的推导；换规则须 re-infer，应用管 shapes、迁移与发布。[G0] [G1] | Free 自管、EE 自管／托管；EE 按每节点 CPU 核授权，另计算存备份；Free 自 11.0 须申请许可证，SE 已停售。[G2] |
| Stardog；在线文档，仅采用既有 9／10 边界 | RDF 与虚拟图；SPARQL；多个命名 reasoning schema。[S0] | SHACL／ICV 可校验数量；显式启用 guard mode 后，违规新增或删除事务失败，不能等同默认拒写。[S1] | 查询时重写，不默认物化；Blackout 的 SL 合并 RDFS／QL／RL／EL 与 SWRL，超选定范围公理被忽略；递归规则有限。schema 图更新自动识别，但不自动跟随 owl:imports；应用补导入、审批及实例清理。[S0] | 本地／Cloud／Marketplace；企业许可、支持／专业服务及算存备份；具体合同计费维度未核实。[S3] |
| Jena＋Ontop；Ontop 5.5.0，Jena 在线文档 | Jena TDB 持久 RDF／Fuseki SPARQL 更新；Ontop 将虚拟 RDF 的 SPARQL 重写为 SQL，数据留源库。[F0] [O0] | Jena SHACL Core／SPARQL 约束需显式配置或 GraphValidation 接入；Ontop 只读，不能承诺写入基数校验。[F1] [O1] | Jena OWL／Mini／Micro 均不完整，通用规则支持前向／后向／混合；底层绕写需 rebind。Ontop 支持 RDFS／OWL 2 QL，不是全 OWL；应用补本体／映射发布、源库写入、联邦路由与删除同步。[F2] [O0] [O1] | 组件自管；Jena、Ontop 及原关系库分别承担算存、备份、运维，源库可能另有许可；不是一个开箱即用数据库。[F0] [O0] |

## 关键边界与时间审计

1. Neo4j 文档已从“无强 schema”的旧式概括前进到 Graph types：2026.02 引入、2026.06 GA，均早于截止日。[N0] [N1] `ALTER CURRENT GRAPH TYPE ADD` 只新增元素，不能给既有元素追加属性；`SET` 替换此前整个 graph type **及约束**；已有数据冲突须先迁移。[N1] [N2] `ALTER` 是所列元素的重新定义，遗漏字段会撤销对应限制，但键／唯一约束保留；`DROP` 元素亦不自动删除键／唯一约束，须按名删，DDL 不等于实例清理。[N3] [N4]
2. Neptune Database 查询的 default graph 是全部 named graphs 的 union，去重返回；未指定写入图则落入 fallback named graph，应用须显式限定图范围。[P3] 重复点 ID 并非一律报错：Gremlin 指定新标签可给已有点增加标签及属性。[P2] Analytics 的 RDF 导入支持不能升级成 SPARQL／OWL 能力；不能把导入 cardinality 当关系度数校验。[A0] [A2]
3. Nebula 3.8.0 文档标明修订于 2026-09-24；较 2.x 的变化包括可无 Tag、默认删点留下边。[B1] [B2] [B4] JanusGraph SIMPLE 限同标签同端点对最多一条；MANY2ONE 限出边、ONE2MANY 限入边、ONE2ONE 双向各最多一条，均不保证“至少一条”。端点约束须 `schema.constraints=true` 配合 `schema.default=none` 才拒绝违规，且不追溯旧数据；最终一致后端还须锁／冲突解决机制，不能只凭 DDL 承诺并发保障。[J0] [J2]
4. RDF 存储、OWL 推理、拒绝非法写入是三层：GraphDB 的功能属性规则可以推导 sameAs，并非 SQL 式数量拒写；QL 限制、SHACL 支持清单均须按配置核对。[G0] [G1] GraphDB read-only schema 不可原位增删，换 schema 须重建库；ArangoDB 3.12 禁止直接删仍被图定义引用的集合，须先调整图定义。[G0] [R3] GraphDB 11.1 于 2025-08-21 发布；Stardog 10 默认 schema 不再取所有本地图，有 2024-03-05 官方支持正文佐证。[G3] [S2] 在线页的 Stardog 11.2 新能力未核实 GA 日期，不纳入已发生结论；Stride 仍列 beta／不建议生产，不承诺全 OWL。[S0]
5. Ontop 5.5.0 发布于 2026-02-14，FAQ 明确无 SPARQL Update；5.0 发布说明已有 SPARQL 扩展规则，但完整递归范围未核实。[O0] [O1] [O2] 除明确固定版本外，在线页不等于历史快照；目标安装版本、插件、云套餐、未注明发布日期的新能力仍待核。所有 AWS 引用均读到所引功能正文；通用“Amazon Neptune”空壳页、失败路径未作为来源。删本体定义后的业务实例保留／删除策略、发布审批、回滚与审计，仍须应用决定。
